# Shared authentication UI

Create these native components when implementing the remaining screens:

- Form fields with labels and associated validation errors.
- Password fields and password-requirement hints.
- Submit buttons with loading/disabled states and duplicate-submission protection.
- Shared success/error messages and pending-verification states.
- Accessible labels, keyboard configuration, focus handling, and status announcements.
- Keep API calls and token storage outside presentation-only components.

Use React Native View, Text, TextInput, and Pressable instead of browser HTML elements.
